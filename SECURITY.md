# Security

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/riteshsonawane1372/boku/security/advisories/new)
rather than a public issue. We aim to acknowledge reports within a week.

## Threat model

Boku reads the open web through AI agents. Everything retrieved is
**untrusted input** that may try to manipulate the agents (prompt injection)
or the output (malicious markup).

### Agent isolation

Each agent is a separate `claude -p` process started with:

- `--restricted`: no shell, code-execution or file-editing tools; user,
  project and local Claude Code settings are ignored
- `--tools WebSearch,WebFetch` (or none): the only capabilities agents have
- `--strict-mcp-config` with no MCP servers, `--disable-slash-commands`
- `--permission-mode dontAsk`: anything not pre-allowed is denied
- `--no-session-persistence`
- a scratch working directory inside the run directory
- a filtered environment: only `PATH`, `HOME`, locale, terminal, temp and
  proxy/certificate variables, plus `ANTHROPIC_*`, `CLAUDE_CODE_*` and
  `CLAUDE_CONFIG_DIR`. Cloud credentials, tokens and `SSH_AUTH_SOCK` are
  removed. Add variables explicitly with `agents.env_passthrough`
  (for example `AWS_PROFILE` when Claude Code uses Bedrock).

Agents never write files. They return JSON that Claude Code validates
against a schema; Boku writes it to disk.

### Output safety

- All agent text is HTML-escaped by the renderer; agents cannot inject markup,
  scripts or styles. Running-header strings are CSS-escaped.
- Charts and diagrams are generated by Boku from numbers and labels, not from
  agent-supplied SVG.
- Chrome renders a local file in a fresh temporary profile and is closed after
  printing. The report HTML loads no remote resources.

### What Boku does not protect against

- A compromised Claude Code installation, or credentials Claude Code itself
  can read (`HOME` is passed through so Claude Code can authenticate).
- Misleading content that is well-sourced but wrong. The fact checker and
  gates reduce this risk; they do not eliminate it. Verify material facts.
- Cost: set `agents.max_cost_usd` / `--max-cost` for unattended runs.
